#### Basic knowledge About CSS and Interview Ques-Ans ####
HTML = Structure-  Defines the content structure (e.g., text, images, buttons).
CSS = Appearance-  Controls the appearance (e.g., colors, fonts, sizing, positioning).


Que: What is CSS?
Ans: CSS (Cascading Style Sheets) is the code used to style a webpage and control how its elements are visually presented to users. While HTML provides the structural skeleton of a page, CSS applies the paint, layout, and typography to make it visually appealing.

Que: Core Benefits of CSS?
Ans: 
    1. Design Flexibility: Changes colors, fonts, backgrounds, and animations.
    2. Responsive Layouts: Adapts designs across mobile, tablet, and desktop screens.
    3. Code Efficiency: Styles multiple webpages using a single stylesheet file.
    4. Faster Loading: Separates design from content to reduce file sizes.

Que: Ways to Add CSS?
Ans: There are 3 Ways to Apply CSS
    1. Inline: Added directly inside an HTML tag using the style attribute.
    2. Internal: Written inside a <style> block in the HTML document's <head>.
    3. External: Linked from a separate .css file (the industry best practice).

Inline CSS-----Not recommended.

}
</style>

Que: What is the difference between margin and padding, and how does the box-sizing property affect them?
Ans: 
    Margin creates space around (outside) an element's border, separating it from other elements. 
    Padding creates space inside an element, separating its content from its own border.
    
    By default, adding padding or borders increases the actual physical size of an element.
    The box-sizing property alters this mathematical formula, controlling whether padding and borders are added to the width/height or absorbed within it.

Que: What is margin collapsing, and when does it occur?
Ans: 
    Margin collapsing is a CSS behavior where the top and bottom margins of adjacent block-level elements combine (collapse) into a single margin, rather than adding together.
    The browser resolves this conflict by applying only the largest single margin value.

Que: What is the difference between setting an element's opacity using opacity: 0.5 versus using an rgba() color value?
Ans: 
    The opacity property applies transparency to the entire element, including its background, borders, text, and all child elements.
    An rgba() value applies transparency exclusively to the specific color property it is assigned to (like the background), leaving the child elements completely opaque.

Que: How do you make a background image scale to completely fill its container without distorting its aspect ratio?
Ans:
    To completely fill a container without stretching or distorting the image, you combine background-size: cover with background-position: center.

Que: What is the difference between em, rem, and px units when styling font sizes?
Ans:
    px is an absolute, fixed static unit, while 
    em and rem are relative units that dynamically recalculate scale based on font-size definitions.

Que: What is a web-safe font stack, and why do we include fallback fonts in the font-family property?
Ans:
    A font stack is a prioritized list of fonts declared in CSS.
    We use fallback fonts because browsers can only render a font if it is locally installed on the user's device or successfully downloaded via a web service (like Google Fonts).
        font-family: "CustomFont", Arial, sans-serif;

Que: Which CSS property would you use to prevent long words or URLs from breaking out of their text container?
Ans:
    To safely control text overflows caused by unbreakable, 
    contiguous strings like long URLs or compound words,
    use overflow-wrap: break-word (formerly known as word-wrap).

Que: How do you create a perfect circle using only HTML and CSS?
Ans:
    To render a perfect circle, you must apply three mandatory properties to an element: ensure the block has an exact 1:1 aspect ratio (equal width and height), and set the border-radius to 50%.

Que: How can you add a border to an element without changing its dimensions or shifting surrounding layout?
Ans:
    Standard CSS borders add thickness outside the content box, which can alter element calculations and create visual "layout shifts". To add a border outline without modifying the box dimensions, you can use either the outline property or an inset box-shadow.

Que: What is the shorthand syntax for setting individual margins or paddings on all four sides of an element?
Ans:
    The shorthand syntax accepts up to four values and processes them sequentially following a clockwise rotation rule: Top, Right, Bottom, Left (abbreviated as TRBL).
