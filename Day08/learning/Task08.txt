How to install Tailwind CSS?
CDN :  <link href="https://unpkg.com/tailwindcss@^2/dist/tailwind.min.css" rel="stylesheet">

Setup :
    📁 Step 1: Open Your Target Project Folder
            cd C:\Users\User\Desktop\work\Frontend_Challenge\Day08
    📄 Step 2: Initialize Your Package Config File
            npm init -y
    📦 Step 3: Execute the Local Installation
            npm install tailwindcss @tailwindcss/postcss postcss

                or

            npm install -D @tailwindcss/cli
    🎨 Step 4: Link Tailwind to Your Source Stylesheet
            @import "tailwindcss";
    🚀 Step 5: Start the Compiler Watch Process
            npx tailwindcss -i ./style.css -o ./dist/output.css --watch
