# 📌 About This Challenge

This repository documents my **60 Days Frontend Development Challenge**.

I am a Computer Science student who wants to become a skilled frontend developer by focusing on **consistent daily learning, project building, and practical coding**.

Instead of only watching tutorials, I will learn new concepts every day and immediately apply them by building real-world projects.
