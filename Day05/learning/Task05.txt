Que: Why Learn Responsive Design?
Ans: 
    Learning Responsive Web Design (RWD) is essential because mobile devices drive approximately 64% of all global web traffic. If a website does not adapt seamlessly to smaller screens, modern users will quickly abandon it.
    More than 60% of users browse websites from mobile devices.

A website that looks good on desktop but breaks on mobile is considered incomplete.
Responsive design is a mandatory skill for every frontend developer.

### Hour 1 - Learn Responsive Design Basics

#### What is Responsive Design?
Ans:
    Responsive Web Design (RWD) is an architectural approach to web development where a single website automatically resizes, shrinks, hides, rearranges, or expands its content to fit perfectly on any screen size. Popularized by web designer Ethan Marcotte, it ensures that your site functions flawlessly whether a user opens it on a giant desktop monitor, a tablet, a smartphone, or a smart watch.


Responsive Design means:
    1. Website adapts to different screen sizes
    2. Works on mobile
    3. Works on tablet
    4. Works on desktop


### Viewport Meta Tag
Solution:
    The Viewport Meta Tag is a single line of HTML code that forces mobile browsers to scale a webpage correctly to fit the user's actual screen size.
    Without it, mobile devices pretend they are desktop monitors (usually 980 pixels wide) and zoom out to fit the whole page. This makes text microscopic, fonts unreadable, and forces users to double-tap or pinch-to-zoom.


Every website should include:
    <meta name="viewport" content="width=device-width, initial-scale=1.0">


### Responsive Units are %
Solution:
    1. Font-Relative Units (Best for Typography & Spacing)
        rem (Root Em)     {1rem = 16px}
        em
    2. Viewport-Relative Units (Best for Full-Screen Layouts)
        vw (Viewport Width)
        vh (Viewport Height)
        vmin / vmax
        lvh / svh / dvh
    3. Container-Relative Units (Best for Grids & Columns)
        % (Percentage)
        fr (Fractional Unit)


| Goal                  | Best Unit     | Why?                                                          |
|-----------------------|---------------|---------------------------------------------------------------|
|    Global Font Sizes  |  rem          | Scales globally if users change browser settings.             |
|   Padding & Margins   |  rem  or  %   | Keeps spacing proportional to text size or layout widths      |
|  Full-Screen Sections |  vh  or  dvh  | Guarantees components stretch exactly to the device edges.    |
|   Grid Column Widths  |  fr  or  %    | Distributes available columns evenly across space layouts.    |


## Hour 2 - Learn Media Queries

### Basic Media Query
Solution:
    A basic media query is a CSS block that applies specific styles to a webpage only when certain conditions are met, such as a minimum or maximum screen width. It is the foundation of responsive web design.

Media or Devices ViewPort Size
    Mobile Phones -   360px to 480px  - Default Styles (No Query)
    Tablets (Portrait) - 768px  - @media (min-width: 768px) { ... }
    Laptops / Tablets (Landscape) - 1024px - @media (min-width: 1024px) { ... }
    Desktop Displays - 1280px - @media (min-width: 1280px) { ... }
    Large Screens / TVs  - 1536px+  -  @media (min-width: 1536px) { ... }

### Examples 

    @media (max-width: 768px) {
        body {
            background-color: lightgray;
        }
    }

Meaning:  When screen width becomes 768px or smaller, apply these styles.

### Mobile Navigation Example

Desktop:

    .navbar{
        display:flex;
        justify-content:space-between;
    }


Mobile:


    @media (max-width:768px){
        .navbar{
            flex-direction:column;
        }
    }

### Responsive Cards Example

Desktop:

    .cards{
        display:flex;
        gap:20px;
    }

Mobile:

    @media (max-width:768px){
        .cards{
            flex-direction:column;
        }
    }
