Learn Semantic HTML
Que: What is Semantic HTML?
Answer: Semantic HTML is the practice of using HTML tags that clearly describe the meaning and purpose of the content they contain, rather than just how it should look.Semantic tags describe the meaning of content.

Que: How Semantic Tag helps us?
Ans: 
    1. readability
    2. SEO {Search engines like Google use these tags to better understand and index your content, which can improve your search rankings}
    3. accessibility { Screen readers use semantic tags as landmarks, allowing users with visual impairments to navigate a page more easily.}
    4. professional coding structure
    5. Code Maintainability { Semantic code is easier for developers to read and manage because the structure clearly follows a logical outline.}

Que: Some Common Semantic Tags Example ?
Ans: 
    <header> - The introductory section of a page or article, often containing a logo or navigation.
    <nav> - A section intended for navigation links.
    <main> - The primary, unique content of the document (only one per page).
    <section> - A thematic grouping of content, typically with a heading.
    <article> - Independent, self-contained content like a blog post or news story.
    <aside> - Content indirectly related to the main text, often placed as a sidebar.
    <footer> - The bottom section of a page, usually containing contact info or copyright data.

Instead of: div tag we can use them || <header></header> | <nav></nav> | <section></section> | <footer></footer> ||

## IMPORTANT FORM TAGS ##
<form>	Defines an HTML form for user input
<input>	Defines an input control
<textarea>	Defines a multiline input control (text area)
<label>	Defines a label for an <input> element
<fieldset>	Groups related elements in a form
<legend>	Defines a caption for a <fieldset> element
<select>	Defines a drop-down list
<optgroup>	Defines a group of related options in a drop-down list
<option>	Defines an option in a drop-down list
<button>	Defines a clickable button
<datalist>	Specifies a list of pre-defined options for input controls
<output>	Defines the result of a calculation

Form Actions: 
1. accept-charset - 	Specifies the character encodings used for form submission
2. action	 - Specifies where to send the form-data when a form is submitted
3. autocomplete	 - Specifies whether a form should have autocomplete on or off
4. enctype	- Specifies how the form-data should be encoded when submitting it to the server (only for method="post")
5. method	 - Specifies the HTTP method to use when sending form-data
6. name	 - Specifies the name of the form
7. novalidate - 	Specifies that the form should not be validated when submitted
8. rel	 - Specifies the relationship between a linked resource and the current document
9. target	 - Specifies where to display the response that is received after submitting the form

Input Restrictions
1. checked	- Specifies that an input field should be pre-selected when the page loads (for type="checkbox" or type="radio")
2. disabled	 - Specifies that an input field should be disabled
3. max	 - Specifies the maximum value for an input field
4. maxlength	 - Specifies the maximum number of character for an input field
5. min	 - Specifies the minimum value for an input field
6. pattern	 - Specifies a regular expression to check the input value against
7. readonly	 - Specifies that an input field is read only (cannot be changed)
8. required	 - Specifies that an input field is required (must be filled out)
9. size	 - Specifies the width (in characters) of an input field
10. step	 - Specifies the legal number intervals for an input field
11. value	 - Specifies the default value for an input field
