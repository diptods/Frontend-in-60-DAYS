# 🎨 Main Project

## Project Name

ChocoBite Landing Page

---

# Project Description

Create a modern chocolate product landing page.

This project combines everything learned so far.

---

# Section 1 - Header

Contains:

- Logo
- Navigation Menu

Example:

```text
ChocoBite

Home Products About Contact
```

Use Flexbox.

---

# Section 2 - Hero Section

Contains:

- Main Heading
- Description
- Call To Action Button
- Hero Image

Example:

```text
Premium Handmade Chocolate

Experience the taste of luxury.

[ Shop Now ]
```

Use Flexbox.

---

# Section 3 - Features Section

Create 3 feature cards.

Examples:

- Premium Ingredients
- Fast Delivery
- Handmade Quality

Desktop:

```text
Feature Feature Feature
```

Mobile:

```text
Feature
Feature
Feature
```

Use Grid.

---

# Section 4 - Products Section

Create 6 chocolate cards.

Each card contains:

- Product Image
- Product Name
- Price
- Short Description
- Buy Button

Desktop:

```text
Card Card Card

Card Card Card
```

Use CSS Grid.

---

# Section 5 - Testimonials

Create 3 customer reviews.

Example:

```text
⭐⭐⭐⭐⭐
Amazing Chocolate!
```

Use Grid.

---

# Section 6 - Newsletter Form

Contains:

- Email Input
- Subscribe Button

---

# Section 7 - Footer

Contains:

- Copyright
- Social Media Links

# Design Requirements

## Colors

Choose:

- Dark Brown
- Chocolate Brown
- Cream
- White

---

## Typography

Use:

```css
font-family: Arial, sans-serif;
```

or

```css
font-family: Poppins, sans-serif;
```

---

## Effects

Add:

- Hover Effects
- Button Hover
- Card Hover

Example:

```css
.card:hover{
    transform:translateY(-5px);
}
```

---
