# 🍫 ChocoBite - Modern Chocolate Brand Landing Page

A premium chocolate brand landing page designed using **HTML5** and **CSS3** with a luxurious dark theme, elegant typography, modern layouts, and smooth user interactions.

---

# 📖 Project Overview

**ChocoBite** is a modern chocolate product showcase website created to practice professional frontend development skills. The design focuses on creating a premium user experience through rich visuals, dark aesthetics, gold accents, glassmorphism effects, and responsive layouts.

This project simulates a real-world chocolate brand website where users can explore products, learn about the company, view customer reviews, and subscribe for future offers.

---

# 🎯 Project Objectives

The main goals of this project are:

* Build a complete landing page using HTML and CSS
* Practice semantic HTML structure
* Create responsive layouts
* Implement Flexbox and CSS Grid
* Design modern UI components
* Apply hover animations and transitions
* Improve visual hierarchy and user experience
* Create a portfolio-worthy frontend project
